# Agent instructions

This repository contains a website-redesign animation skill, not an implemented renderer.

## Start here

Read `skills/websup-website-redesign/SKILL.md` and its three references before planning or implementing a film. Paths inside that skill are relative to its own directory.

## Working rules

- Use the supplied 35-second case unless the user provides a newer brief.
- Preserve authentic before/after assets and the client site's branding.
- Keep WebsUp presentation branding separate from the client website.
- Find the separately installed motion-broll engine before depending on it. This repository does not contain it.
- A brief is not an implementation, and an implementation is not a verified render. State the actual delivery status.
- Do not commit secrets, client captures, private designs, licensed audio or generated videos to this repository without explicit authorization.
- Never publish or modify a production website merely to create an animation.

Read the root README for a starting prompt and the quality checklist for verification requirements.
